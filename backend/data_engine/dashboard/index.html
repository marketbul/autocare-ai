How to Collect Real Multi-Source Data into Localhost

A. YouTube (Automated Official API):
1. Open Google Cloud Console → Enable YouTube Data API v3 → Create an API Key.
2. Paste the key below (or put YOUTUBE_API_KEY=... in backend/.env) and click Run YouTube Collection.
B. Facebook, PakWheels & Blogs (ToS-Compliant):
Automated scraping is disabled by project policy. Download a CSV template below, enter public findings (URL + vehicle + symptoms + solution), and upload or paste the CSV to clean & ingest immediately.

1. YouTube Official Data API v3 Collector

Collects public automotive video metadata (titles, descriptions, channel, view/like counts, duration). Never downloads copyrighted video/audio automatically.

2. Import Research CSV (Facebook / PakWheels / Blogs / Field)

Imports structured research sheets cleanly. Mechanic interviews without consent=yes are automatically rejected. Owner reports automatically redact phone numbers, CNICs, and license plates.

Facebook Template PakWheels Template Blogs Template Mechanic Template Owner Template

3. Submit Single Vehicle Problem / Mechanic Observation

Validates via Pydantic, detects language, scrubs personal identifiers, and auto-matches the 18-category taxonomy.

4. Upload Authorized Media Asset (Audio / Image / Video)

Stores permitted audio recordings (engine knocking/squealing) or dashboard/component photos in data/media_vault/ with SHA-256 checksums.

5. Process Authorized Video (Extract Audio WAV + Screenshots + Talk Claims)

Upload an owned, consent-granted mechanic video or Creative Commons clip. Uses ffmpeg to extract 16kHz audio and timestamped JPG screenshots, runs speech/transcript claim extraction (symptoms, causes, PKR costs), and adds it to your AI-Agent dataset.
